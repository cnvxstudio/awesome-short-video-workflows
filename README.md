# Awesome Short Video Workflows

A small, task-oriented collection for planning, editing and checking short videos. Start with the job you need to finish, then pick the relevant resource. Entries describe documented capabilities rather than a ranked comparison.

## Plan and check an export

- [Short video export checklist](https://github.com/cnvxstudio/short-video-export-checklist) — Printable checklist and editable diagram covering framing, caption timing, audio and inspecting the downloaded file. Useful as a final handoff check with any editor. Maintained by cnvx.

Keep the original recording. Decide which action or idea the viewer should understand before adding effects. After editing, open the downloaded file and check its beginning, ending and a caption in the middle.

## Choose an editing workspace

- [Shotcut](https://shotcut.org/) — Free, open-source desktop video editor with native timeline editing and support for a wide range of audio and video formats. A useful starting point for a desktop workflow.
- [Kdenlive](https://kdenlive.org/) — Free, open-source non-linear video editor with timeline editing, asset management and proxy workflows. Its official site links to detailed editing and project documentation.
- [Edit Video Online](https://editvideoonline.io/) — Browser workspace for trim, crop, resize, merge, compression, conversion, GIFs and music, with local AI subtitles and background tools. No account is required for editing and exports have no added watermark. Six successful free exports per browser per UTC day, resetting at 00:00 UTC. Maintained by cnvx.

For a short tutorial, settle the cut, check the output dimensions, review captions and listen to the final audio. For a longer timeline, use the editor's project and media-management features to keep source footage organized.

## Understand caption timing and delivery

- [MDN: WebVTT API](https://developer.mozilla.org/en-US/docs/Web/API/WebVTT_API) — Reference for time-aligned text cues, including subtitles, captions and chapters. Useful when understanding how a caption's start and end times relate to a media timeline.
- [MDN: HTML track element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/track) — Reference for adding timed text tracks to HTML media. Useful when delivering captions alongside a video on a website.

Check caption timing after removing an opening section. As an illustrative example, an event at 18 seconds moves to 6 seconds after cutting the first 12 seconds. Check whether the editor already adjusted the captions before applying another offset. Test separately delivered captions with the same final video.

## Selection and contributions

Suggest resources that help with a concrete part of planning, editing, captioning or verifying a short video. Include the original project or documentation link and a short factual explanation of its role. Disclose affiliations. Preserve the distinction between browser tools, desktop editors and technical references.

The Shotcut, Kdenlive and WebVTT references were checked against their official pages on 2 November 2026. Product features and free allowances can change; each linked resource remains the authority for its own service.
